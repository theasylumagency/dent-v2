# პაციენტის გზამკვლევის განახლება

```sh
npm run data:patient-guide
npm run data:patient-guide -- --check-db
npm run data:patient-guide -- --update-existing
npm run data:patient-guide -- --add-draft
```

- პირველი ბრძანება ამოწმებს ტექსტებსა და ყდის ფაილებს მონაცემთა ბაზასთან დაკავშირების გარეშე. `--check-db` ბაზიდან მხოლოდ ჩანაწერების სტატუსებს კითხულობს.
- `--update-existing` არსებულ ოთხ გამოქვეყნებულ ჩანაწერს პოულობს slug-ით და ცვლის ტექსტებსა და SEO ველებს სამ ენაზე. ასევე ანახლებს ყდას. ინარჩუნებს ჩანაწერის ID-ს, URL-ს, თარიღსა და კატეგორიას. თუ რომელიმე ჩანაწერი აკლია ან მასზე აქტიური დრაფტია, ბრძანება ცვლილებების დაწყებამდე ჩერდება.
- `--add-draft` ახალ სტატიას ერთი დრაფტის სახით ამატებს ქართულად, ინგლისურად და რუსულად. განმეორებით გაშვებისას მხოლოდ დრაფტის ცარიელი ენობრივი ვერსიები ივსება. სტატია Payload-ის ადმინისტრატორიდან გამოაქვეყნეთ სამივე ვერსიისა და თარიღის შემოწმების შემდეგ.
- ორივე ჩაწერის ბრძანება გაუშვით მიზნობრივ გარემოში. არსებული სტატიების განახლება გააკეთეთ Next.js-ის production build-მდე, რადგან CLI-დან Payload-ის hook Next-ის ქეშს ვერ განაახლებს.

ოთხივე არსებული სტატიის ყდა კლინიკის მოწყობილობის არსებული ფოტოა. ახალი სტატიის ყდა კონსულტაციის გენერირებული სარედაქციო ილუსტრაციაა. კლინიკის დაბრუნებულ დოკუმენტში მითითებულ ორ რედაქტორს შორის საჯარო პროფილი მოიძებნა ნინო ოსაძისთვის. ანრი ლაგვილავა მითითებულია სახელით.

ინგლისური და რუსული ტექსტები ინახება `docs/blog/en/` და `docs/blog/ru/` საქაღალდეებში. თითოეულს აქვს საკუთარი სათაური, აღწერა და შესაბამისი ენის სერვისებისა და ექიმის გვერდების ბმულები.
