## კრიტიკული

**ჩაწერის ფორმა ახლა ნამდვილად აგზავნის.** `setTimeout`-ის ნაცვლად — `POST /api/booking`.
`src/app/api/booking/route.ts`: სერვერული ვალიდაცია, honeypot, rate limit (5 მოთხოვნა / 10 წთ IP-ზე), Resend-ით მიწოდება, escape-ული HTML.

> თუ `RESEND_API_KEY` და `BOOKING_FROM` არ არის გაწერილი, endpoint აბრუნებს **503**-ს და ფორმა აჩვენებს შეცდომას ტელეფონის ნომრით. ეს განზრახაა: ყალბი „წარმატება“ იმას ნიშნავდა, რომ პაციენტის განაცხადი უბრალოდ ქრებოდა. იხ. `.env.example`.

**გასწორდა runtime bug.** `event.currentTarget.reset()` `await`-ის შემდეგ — React დისპატჩის ბოლოს `currentTarget`-ს `null`-ად აყენებს, ანუ reset ყოველთვის იგდებდა შეცდომას. ახლა `form` იჭერს ცვლადში await-მდე.

**ნამდვილი საკონტაქტო მონაცემები.** `+995 511 21 16 16` (მობილური, WhatsApp), `+995 32 250 16 16` (ქალაქის), `vake_dent@tcc.ge`.
**სამუშაო საათები 10:00 → 9:00** სამივე ლექსიკონში, hero-ს ფაქტებში და JSON-LD-ში.

## ქართული ტიპოგრაფია

`:lang(ka)` ბლოკი `globals.css`-ში ასწორებს იმას, რაც Cormorant→Noto fallback-ს მოჰყვა:

| იყო | გახდა |
|---|---|
| `letter-spacing: -0.015em` სათაურებზე | `0` — მხედრული უარყოფით tracking-ს არ იტანს |
| `uppercase` 10–11px-ზე + 0.22em tracking (~12 ადგილი) | `text-transform: none`, tracking 0.06em, ზომა 13px |
| სინთეზური italic hero-ს სათაურზე | `font-style: normal` |

მიკრო-ლეიბლები გაერთიანდა ერთ `.label-micro` კლასში — ადრე იგივე სტილი 12 ადგილას იყო inline გაწერილი, რაც per-locale გასწორებას შეუძლებელს ხდიდა.

ძირითადი ტექსტი ყველგან **16px**-ია (იყო 14px).

| ელემენტი | იყო | გახდა |

| ფორმის ველი | 1.22 : 1 | **3.45 : 1** |

## წვდომადობა

- მობილური drawer → `role="dialog"` + `aria-modal` + **focus trap** + focus დაბრუნება ღილაკზე
- **JS-ის გარეშე გვერდი აღარ არის ცარიელი** — `.reveal`-ის დამალვა ახლა `.js` კლასზეა მიბმული, რომელსაც inline script ხატვამდე ამატებს
- `prefers-reduced-motion` **ვიდეოსაც ითვალისწინებს** (CSS წესი მას ვერ წვდებოდა) + პაუზის ღილაკი
- `<dl>` სემანტიკა Hero/Clinic/Contact-ში: label → `dt`, value → `dd` (იყო `dt` დამალული და ორივე `dd`-ში)
- `<nav aria-label>` — იყო „მთავარი“, გახდა „მთავარი ნავიგაცია“
- ფორმა: per-field შეცდომები, `aria-invalid`, focus პირველ არასწორ ველზე, სტატუსი და თანხმობის ტექსტი **გაიყო** (წარმატებისას თანხმობა აღარ ქრება)
- მეგა-მენიუს `<h2>` → `<p>` (ყოველ გვერდზე ირენდერებოდა და outline-ს ბინძურებდა)

## მოძრაობა და წარმადობა

- Reveal: **1s → 600ms**, stagger 280ms → 45ms, `threshold` 0.08 → 0
- Hero-ს ვიდეო **მობილურზე აღარ ჩამოიტვირთება** — LCP ახლა `<Image priority>` პოსტერია; ვიდეო ერთვება მხოლოდ ≥1024px + motion OK + არა Save-Data
- `transition-all` (4 ადგილი) → კონკრეტული თვისებები
- გუნდის ფოტოები: 900ms → 500ms, სამი თვისების ნაცვლად ორი
- სერვისის ბარათებს **მოეხსნა hover-translate** — pill-ები კურსორის ქვეშ იძვროდნენ
- ხატულების `sizes` 64px → 128px (retina-ზე ბუნდოვანი იყო)

## რიტმი და SEO

- სამსაფეხურიანი ვერტიკალური რიტმი (`.section-tight` / `.section` / `.section-airy`) ერთგვაროვანი `py-24 lg:py-32`-ის ნაცვლად

- `scroll-padding-top` 6rem → 5rem (სქროლილი header 64px-ია)
- JSON-LD: `email`, `hasMap`, `medicalSpecialty`, `areaServed`, `contactPoint[]`, `availableService[]`
- ახალი `sitemap.ts` + `robots.ts`
- `x-default` → `/en` (იყო `/ka`)
