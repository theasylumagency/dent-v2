## ✅ კარგი ამბავი

**შენს ფაილში სწორი ვექტორი უკვე არის.** მასში ორი ვერსიაა ერთმანეთზე დაწყობილი:

| ფენა | რა არის | ვარგისია? |
|---|---|---|
| **`.st1`** — 60 path, `fill:none; stroke:#000; stroke-width:2` | ნამდვილი, ხელით დახატული შტრიხული ვექტორი | ✅ **ზუსტად ის, რაც მჭირდება** |
| **`.st0` + ~170 უკლასო path** | Image Trace-ის შედეგი: თეთრი ფონის ოთხკუთხედი + ასობით მიკროსკოპული ლაქა | ❌ ამოსაღებია |

ანუ Illustrator-ში ორივე ფენა დარჩა ჩართული ექსპორტისას. საკმარისია trace-ის ფენა გამორთო/წაშალო.

**შედეგი:** 35 KB → **5.7 KB** (6× პატარა), ერთი ფაილიდან ამოღებული 170 ზედმეტი path.

## ❌ სამი პრობლემა, რაც უნდა გაასწორო

### 1. თეთრი ფონი კვლავ იქ არის
`.st0{fill:#FFFFFF;}` და პირველი path არის მთელი კანვასის ოთხკუთხედი (`M264.57,529.11 ... 0,0 → 529,529`). ეს ზუსტად ის თეთრი კვადრატია, რომელიც ბარათებზე ჩანდა.

### 2. Image Trace-ის ფენა
ასობით path ტიპის `M264.72,379.24c-0.19,0.23-0.34,0.42-0.49,0.61` — ეს 0.6 ერთეულის ლაქებია 529-იან კანვასზე, ანუ ეკრანზე 0.1 პიქსელი. უხილავია, მაგრამ ფაილს 6-ჯერ ზრდის.

### 3. `stroke-width: 2` ძალიან თხელია
დათვლილი: 2 ÷ 366 (viewBox) × 80px = **0.44 პიქსელი**. სწორედ ამიტომ ჩანდა ბუნდოვან ლაქად. დავარენდერე ოთხი ვარიანტი და **4.5 არის სწორი მნიშვნელობა**.

## 🖥️ Illustrator-ში

1. Layers პანელში **გამორთე ან წაშალე trace-ის ფენა** (ის, სადაც შავი შევსებული ფორმებია)
2. დარჩენილი შტრიხული ფენა მონიშნე → `Object → Artboards → Fit to Selected Art` (ცარიელი ველი მოიჭრება)
3. `Window → Stroke` → Weight დააყენე ისე, რომ artboard-ის სიგანის **1.23%** იყოს
   (366-იან viewBox-ზე ეს 4.5-ია)
4. Cap და Corner → **Round**
5. `File → Save As → SVG`
   - Styling: **Presentation Attributes** (არა Internal CSS)
   - Object IDs: Minimal
   - Decimal: 2
   - Responsive: ✓

## 🔵 ლოგო — ცალკე ამბავი

**`source/tmp/logo.svg` არ შეცვლილა** — ის ბაიტ-ბაიტ იგივეა, რაც `source/logo.svg`. იგივე `.cls-1{fill:#fff;}`, იგივე 13 თეთრი path, ბრენდის ფერის გარეშე.

**მაგრამ ეს აღარ გვჭირდება.** დავარენდერე ტესტი: ავიღე ერთი შავი path („a" ასო) წითელ ფონზე, თეთრი path-ების გარეშე — და **ასოს ხვრელი ნამდვილი ხვრელი აღმოჩნდა**, წითელი გამოჩნდა.

ანუ 12 თეთრი counter-path **სრულიად ზედმეტია** — შავ path-ებს ხვრელები `fill-rule`-ით უკვე აქვთ.

ამიტომ `public/brand/logo.svg`-ში შევცვალე:

```css
.cls-1 { display: none; }   /* იყო: fill: #fbf7f1 */
```

**ლოგო ახლა ნამდვილად გამჭვირვალეა — ნებისმიერ ფონზე.** Illustrator-ში მუშაობა აღარ გჭირდება.
