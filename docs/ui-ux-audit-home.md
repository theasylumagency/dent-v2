**მაგრამ გვერდი ჯერ არ არის „იდეალური“ სამი ფუნდამენტური მიზეზით:**

2. **პრემიუმ ტიპოგრაფია ქართულ ენაზე არ ჩანს.** Cormorant Garamond ქართულ გლიფებს არ შეიცავს → ქართველი მომხმარებელი ხედავს Noto Serif Georgian-ს. ანუ მთავარი აუდიტორია ბრენდის ტიპოგრაფიულ იდენტობას საერთოდ ვერ ხედავს.
3. **ჩაწერის ფორმა მუშაობს „თითქოს“.** `setTimeout(700)` → „წარმატება“. პაციენტი ფიქრობს, რომ ჩაიწერა. არავინ დაურეკავს.

## 🟡 P2 — ქართული ტიპოგრაფია (ბრენდის უხილავი პრობლემა)

### 15. Cormorant ქართულად არ არსებობს
`--font-display: Cormorant_Garamond, Noto_Serif_Georgian, ...`

Cormorant-ს ქართული გლიფები **არ აქვს** → ქართულ ვერსიაში (ძირითადი locale!) ყველა სათაური Noto Serif Georgian-ით დაიხატება. ეს სრულიად სხვა ხასიათის შრიფტია: დაბალკონტრასტიანი, ჰუმანისტური, ნეიტრალური. Cormorant-ის მაღალი კონტრასტი და ელეგანტურობა — რაზეც მთელი „პრემიუმ“ განცდაა აგებული — ქართველი პაციენტისთვის უბრალოდ არ არსებობს.

**ვარიანტები:**
- **A (რეკომენდებული):** აირჩიე ქართული display-შრიფტი, რომელსაც *ჰგავს* Cormorant-ის ხასიათი და ააგე ლათინურიც მასზე — ერთი იდენტობა სამივე ენაზე.
- **B:** დატოვე Noto Serif Georgian, მაგრამ **ლათინურიც** მასზე გადაიყვანე — ნაკლებად ლამაზი, სამაგიეროდ თანმიმდევრული.
- **C:** მიიღე განსხვავება, ოღონდ ქართულისთვის ცალკე დაარეგულირე ზომა/tracking/line-height (იხ. #16, #17).

### 16. `text-transform: uppercase` ქართულზე არაფერს აკეთებს
მხედრული ერთრეგისტრიანია. გვერდზე ~12 ადგილას გვაქვს `uppercase tracking-[0.2em]` 10–11px-ზე (`.eyebrow`, ყველა `dt`, ფუტერის სათაურები, ფორმის ლეიბლები). ქართულად შედეგი: **პაწაწინა ტექსტი უზარმაზარი ღრეჩოებით და ყოველგვარი კაპიტალიზაციის ეფექტის გარეშე** — ეს ტეხილად გამოიყურება.

**გამოსავალი:** `:lang(ka)`-სთვის eyebrow/label — მოზარდე ზომა (12–13px), tracking `0.08em`-მდე, `uppercase` მოხსნილი, აქცენტი `font-weight`-ით.

### 17. ორი დამატებითი ქართული პრობლემა
- `letter-spacing: -0.015em` h1–h3-ზე: მხედრული უარყოფით tracking-ს ცუდად იტანს — ასოები ერთმანეთს ეკვრის. `:lang(ka)`-ზე `0` ან `+0.005em`.
- `italic` hero-ს მეორე სტრიქონზე: Noto Serif Georgian-ს **დახრილი სტილი არ აქვს** → ბრაუზერი სინთეზურ oblique-ს ხატავს. 96px-ზე ეს თვალშისაცემად ცუდია. `:lang(ka)`-ზე ჩამოხსენი italic.

### 18. ძირითადი ტექსტი პატარაა
სექციების უმეტესობაში `text-sm` (14px), `sm:`-ზე ხდება 16px. მხედრულს ლათინურზე მეტი ოპტიკური ზომა სჭირდება იმავე წაკითხვადობისთვის. მობილურზე მინიმუმ 16px, `line-height` 1.7.

### 20. Hero-ს გრადიენტული სათაური კონტრასტს ვერ ჭრის
`.text-gradient` მთავრდება `accent-400`-ით = **2.28 : 1** ivory-ზე. დიდი ტექსტისთვისაც კი საჭიროა 3:1. გარდა ამისა `color: transparent` — თუ `background-clip: text` ჩავარდა, სათაური **უხილავია**.

```css
.text-gradient { color: var(--color-accent-600); }  /* fallback ჯერ */
@supports (background-clip: text) { /* შემდეგ გრადიენტი */ }
```
და გრადიენტის ღია ბოლო გადაიტანე `accent-500`-ზე.

### 21. JS-ის გარეშე გვერდი ცარიელია
`.reveal { opacity: 0 }` — თუ JS დაგვიანდა/ჩავარდა, კონტენტის უმეტესობა უხილავია. სამედიცინო საიტისთვის სახიფათოა.
**გამოსავალი:** `<html>`-ს სინქრონულად დაადე `js` კლასი (inline script `<head>`-ში) და `.reveal`-ის საწყისი მდგომარეობა მხოლოდ `.js .reveal`-ზე გაუშვი.

### 22. მობილური drawer არ არის dialog
არ აქვს `role="dialog"`, `aria-modal="true"`, focus trap. გახსნის შემდეგ Tab გადის უკან, გვერდის ლინკებზე. ასევე focus არ ბრუნდება ღილაკზე დახურვისას.

### 23. მეგა-მენიუ hover-ზეა აწყობილი
`onMouseEnter` + 140ms დაყოვნება, `<button aria-expanded>`-ს არ აქვს `aria-controls`. `onFocus={openMega}` ხსნის Tab-ზე, მაგრამ 21 ლინკის გავლის შემდეგ დახურვის ლოგიკა მხოლოდ Escape-ია. კლავიატურით სავიგაცია არასრულია.

### 24. წვრილმანები
- `<nav aria-label={dict.nav.home}>` = „მთავარი“ — შეცდომითი ლეიბლი მთელი ნავიგაციისთვის.
- `<dl>`-ებში `<dt>` არის `sr-only`, ხოლო value **და** label ორივე `<dd>`-შია. სწორია: label → `dt`, value → `dd`. (Hero `facts`, Clinic `stats`.)
- `Atmosphere`-ის alt = „ინტერიერი“, თუმცა სურათი atmosphere-placeholder-ია — alt არ ემთხვევა.
- სქროლის მინიშნება (`hero.scroll`) დეკორატიულია — გახადე `<a href="#clinic">`.
- Hero-ს სამუშაო საათების ბარათი `hidden sm:block` — **მობილურზე საათები ქრება**. კლინიკისთვის ეს ტოპ-3 ინფორმაციაა.
- `aria-live` რეგიონში ერევა სტატიკური თანხმობის ტექსტი და დინამიური სტატუსი: წარმატების შემდეგ **თანხმობის ჩანაწერი ქრება**. გაყავი ორ ელემენტად.
- წარმატებისას focus არ გადადის შეტყობინებაზე.

## 🟢 P3 — მოძრაობა და წარმადობა

### 25. Reveal ანიმაცია ნელია
`1s` + stagger 280ms-მდე → სერვისების ბადე სრულად ჩნდება ხედში შესვლიდან **~1.3 წამში**. აღიქმება როგორც „ჩამორჩენა“. **600ms-ზე ჩამოიყვანე**, stagger 40–60ms.
`rootMargin: "0px 0px -12%"` + `threshold: 0.08` მაღალი ელემენტებისთვის კიდევ აყოვნებს — მაღალ ბლოკებზე `threshold: 0`.

### 26. Hero-ს ვიდეო
- `autoPlay loop` **არ ითვალისწინებს `prefers-reduced-motion`-ს.** გლობალური CSS წესი მხოლოდ CSS ანიმაციებს ჩლუნგავს — `<video>` მაინც უკრავს. სწორედ ეს არის ის, რაც reduced-motion-ს უნდა გამორთოს.
- პაუზის/ხმის კონტროლი არ არსებობს, თუმცა ლექსიკონში `muteOn` / `muteOff` **უკვე გაწერილია** და გამოუყენებელია.
- მობილურზე ვიდეო მაინც იტვირთება. `lg`-ზე ქვემოთ აჯობებს მხოლოდ `<Image priority>` პოსტერი.
- proportions იცვლება `4/3 → 4/5` (lg): ერთი და იგივე ფაილი `object-cover`-ით პორტრეტში მკვეთრად ჩამოიჭრება — კადრირება რისკზეა.

### 27. Backdrop-filter-ების დასტა
`.glass` (blur 18px + saturate) + მეგა-მენიუ `backdrop-blur-2xl` + drawer `backdrop-blur-2xl` + header `backdrop-blur-xl`. ეს გვერდის ყველაზე ძვირი ოპერაციაა; საშუალო Android-ზე header-ის გადასვლა დაიწყებს jank-ს.

### 28. `transition-all duration-500` header-ზე (2 ადგილას)
ანიმირდება `height` და `max-height` → layout thrash ყოველ სქროლის ზღვარზე. გადაიყვანე `transform`/`opacity`-ზე ან დააფიქსირე კონკრეტული თვისებები.

### 29. სხვა
- ხატულები (`/services/*.webp`) რასტრულია და 64px-ზე ჩნდება `sizes="64px"`-ით → **retina-ზე ბუნდოვანი**. ხაზოვანი ხატულები SVG უნდა იყოს.
- 8+ `aura` ბლობი, თითოეული `blur(110px)` — ღია ფონზე თითქმის არ ჩანს, სამაგიეროდ paint-ს ხარჯავს. ან გააძლიერე, ან მოხსენი.
- `.grain` მხოლოდ Hero-ზეა — ერთი სექციის ტექსტურა შეუსაბამობად აღიქმება, არა ხელწერად.
- `Technology`-ის `sticky top-28` ზის `overflow-hidden` სექციაში — მუშაობს, მაგრამ მყიფეა.
- `Atmosphere` იყენებს `h-[50vh]` → მობილურზე ბრაუზერის პანელის გამო ხტუნავს. `dvh`.
- `scroll-padding-top: 6rem` (96px) vs სქროლილი header 64px → ღუზაზე გადასვლისას ~32px ჭარბი ჰაერი.
- Drawer-ის ზედა spacer `h-20`, header კი სქროლილ მდგომარეობაში `h-16` — 16px აცდენა.
- `<main>`-ს არ აქვს ზედა padding; მას Hero-ს `pt-28/pt-40` ანაზღაურებს. ყოველ ახალ გვერდს ეს ხელით მოუწევს გახსენება.
