# ლოგო და სერვისების აიქონები — რა გავაკეთე და რა გჭირდება

## 1. ლოგო — `public/brand/logo.svg`

### რა აღმოჩნდა

ფაილი Illustrator-ის „გაბრტყელებული" ექსპორტია. თეთრი ფონი **ერთი** ელემენტი არ იყო — ფაილში **13 თეთრი path** არის:

| # | რა არის | რას აკეთებს |
|---|---|---|
| 1 | დიდი path, რომელიც viewBox-ის ოთხივე კუთხეს ეხება | **თეთრი ფონის ფირფიტა** |
| 2–13 | პატარა ფორმები | **ასოების ხვრელები** (counter-ები — „ო"-ს, „ა"-ს შიგნითა სიცარიელე) და emblem-ის დეტალები |

ანუ თუ 13-ვე თეთრ path-ს უბრალოდ წავშლი, ასოების ხვრელები ამოივსება და ლოგო ლაქებად გადაიქცევა.

### რა შევცვალე (2 ატრიბუტი, path-ის მონაცემებს არ შევხებივარ)

```svg
<!-- იყო -->
<svg ... viewBox="0 0 521.43 453.83">
  <defs><style>.cls-1{fill:#fff;}</style></defs>
  <path class="cls-1" d="M268.3,645H40.64...">

<!-- გახდა -->
<svg ... viewBox="0 0 521.43 453.83" fill="#7AC7EF">
  <defs><style>.cls-bg{fill:none;}.cls-1{fill:#fbf7f1;}</style></defs>
  <path class="cls-bg" d="M268.3,645H40.64...">
```

- **ფონის ფირფიტა** → `fill: none` (გამჭვირვალე)
- **ხვრელები** → `#fbf7f1` (გვერდის ivory ფერი) — უხილავია ყველა ზედაპირზე, სადაც ლოგოა (`ivory-100`, `ivory-50`, drawer)
- **დანარჩენი path-ები** → მემკვიდრეობით იღებენ root-ის `fill="#7AC7EF"`-ს

> **შეზღუდვა:** ლოგო ახლა გამჭვირვალეა, მაგრამ **მხოლოდ ღია ივორი ფონზე**. მუქ ან ფერად ფონზე ხვრელები ivory ლაქებად გამოჩნდება. სრულად გამჭვირვალე ვერსიისთვის სჭირდება სუფთა ექსპორტი (იხ. ქვემოთ).

### ⚠️ კონტრასტი — გასათვალისწინებელი

`#7AC7EF` ivory ფონზე (`#fbf7f1`) = **1.75 : 1**.

ლოგოებზე WCAG არ ვრცელდება, ანუ დარღვევა არაა. მაგრამ ვიზუალურად — `h-11` (44px) სიმაღლეზე, თხელი სერიფული ასოებით, ღია ცისფერი ღია ივორზე **გაცრეცილად გამოიყურება**. განსაკუთრებით ლეპტოპის ეკრანზე დღის შუქზე.

**ალტერნატივა — ორფერიანი lock-up** (სტანდარტული და გაცილებით ძლიერი): emblem ბრენდის ცისფერში, wordmark მუქ ნაცრისფერში.

ორი ჩასწორება:

```svg
<!-- 1. root: -->  fill="#1b2126"
<!-- 2. emblem-ის path-ს (რომელიც იწყება M268.3,645a10.14) დაამატე: -->
<path fill="#7AC7EF" d="M268.3,645a10.14...
```

მითხარი და გავაკეთებ — 30 წამის საქმეა.

### სუფთა ექსპორტი (თუ Illustrator-ზე გაქვს წვდომა)

1. ფონის თეთრი ოთხკუთხედი — **წაშალე**
2. ასოები და emblem — მონიშნე ყველა → `Pathfinder → Unite`, შემდეგ `Object → Compound Path → Make`
   ეს ხვრელებს `fill-rule`-ით გააკეთებს ცალკე თეთრი ფორმების ნაცვლად → ლოგო ნებისმიერ ფონზე იმუშავებს
3. `File → Export → SVG`, `Styling: Presentation Attributes`, `Responsive: ✓`
4. ფერი დატოვე შავად — root-ზე `fill` ისედაც გადაფარავს

**PNG არ გირჩევ.** ლოგო header-ში ზომას იცვლის სქროლზე (44px → 36px) და retina-ზე 3× სჭირდება. SVG აქ ობიექტურად სწორი ფორმატია.

## 2. სერვისების აიქონები

### სამი პრობლემა, არა ერთი

გავხსენი `Diagnostics.webp` და ვნახე:

**ა) თეთრი ფონი** — თეთრი კვადრატი ღია ცისფერ ფილაზე. ეს გავასწორე.

**ბ) ხაზები ძალიან თხელია.** წყარო ~350px-ია, გამოსახულება 80px — ანუ **0.23× მასშტაბი**. 1.5px ხაზი ეკრანზე 0.35px ხდება. ეს პიქსელზე ნაკლებია → ბრაუზერი მას ნაცრისფერ ბუნდოვან ლაქად ხატავს.

**გ) კანვასის შიგნით ბევრი სიცარიელეა** + წერტილოვანი გარე რგოლები, რომლებიც 80px-ზე უბრალოდ ხმაურად იქცევა.

### რა გავაკეთე ახლა (აქტივები არ შემიცვლია)

```jsx
className="object-contain mix-blend-multiply"   // + isolate მშობელზე
```

`mix-blend-mode: multiply` თეთრს ფილის ფერში ხსნის — თეთრი კვადრატი გაქრა, მუქი ხაზები დარჩა. მუშაობს იმიტომ, რომ ფილა (`accent-50`) აიქონის ყველა მელანზე ღიაა.

ასევე: ფილა 64px → **80px**, მოვხსენი `p-1.5` (აიქონს ისედაც აქვს შიდა padding).

**ეს ნახევარი გამოსავალია.** (ბ) და (გ) კვლავ პრობლემაა.

### რა მჭირდება შენგან — SVG (რეკომენდებული)

| პარამეტრი | მნიშვნელობა |
|---|---|
| ფორმატი | SVG, ხაზები **`stroke`-ად და არა outline-ად** (რომ სისქე რეგულირებადი იყოს) |
| ფონი | ❌ `<rect>` ფონი არ უნდა იყოს |
| კანვასი | artwork-ზე მოჭრილი — შიდა padding მოხსენი, `viewBox="0 0 64 64"` |
| `stroke-width` | ისეთი, რომ **80px-ზე ≥1.25px** გამოვიდეს. 64-იან viewBox-ზე ეს ≈ **1px** |
| ფერი | `stroke="currentColor"` — ფერს CSS-ით ვმართავ |
| დეტალები | **წერტილოვანი გარე რგოლები მოაშორე** — 80px-ზე ისინი არ იკითხება |

თუ SVG შეუძლებელია → **PNG**: 320×320, გამჭვირვალე ფონით, მოჭრილი, ხაზის სისქე ≥5px.

### სტრუქტურული შენიშვნა

ეს artwork **200px+ ზომაზეა დახატული**. 80px-ზე მისი უბრალოდ შემცირება არ იმუშავებს — რაც არ უნდა კარგი ექსპორტი გააკეთო. ორი გზაა:

1. **გამოვიყენოთ დიდად** — მაგ. სერვისების ბარათებში აიქონი გახდეს 120–140px, ან ცალკე ბანერად
2. **გავამარტივოთ პატარა ზომისთვის** — მხოლოდ კბილი + ერთი რგოლი, სქელი ხაზით, წერტილების გარეშე

მე მეორეს გირჩევ. პირველი გამოსავალიც მუშაობს, თუ დიზაინი ამას იტანს.

### როცა SVG მექნება

კოდის ცვლილება პატარაა, მაგრამ **`next/image`-ს ვერ გამოვიყენებ** — `<img>`-ის შიგნით `currentColor` არ მემკვიდრეობს. inline SVG კომპონენტად გადავიტან (როგორც `ui/icons.tsx`-შია). მაშინ აიქონები ავტომატურად აიღებენ ბრენდის ფერს და hover-ზეც შეიცვლებიან.
